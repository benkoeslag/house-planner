# Cabinet planner prototype

`cabinet-planner.html` is the single-file kitchen cabinet planner built with the owner during planning, before this repository existed. It is kept here **unchanged** as the reference for M2: every rule the new cabinet engine carries over is written out in [`../cabinet-rules.md`](../cabinet-rules.md), and the engine's tests pin the same numbers.

- **Do not edit it.** If a rule needs to change, change it in the new code and in `cabinet-rules.md`, and record the change there. The prototype stays as it was so old results can always be checked.
- **To run it,** open the file in a browser. It needs no server and keeps its work in that browser's local storage under the key `frameless-planner-v1`, separate from House Planner.
- **Version kept:** SHA-256 `312c6ad33bf3b06a703486ee13f99fe9ed8c27c95a235d7918363bb6b29a5530`, copied on 2026-11-01.

It is not part of the app build and is not loaded by the app.
