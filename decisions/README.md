# Architecture Decision Records

Record consequential choices in a short ADR: runtime, database, identity, communication protocol, hosting, or a meaningful change to existing behavior.

1. Copy [ADR-TEMPLATE.md](ADR-TEMPLATE.md) to `ADR-001-short-title.md`, using the next unused number.
2. Describe the concrete problem, constraints, alternatives, and proposed choice.
3. Mark the record Proposed until the responsible decision maker accepts it.
4. Link the associated issue or PR and identify the decision maker.
5. When a decision changes, create a new ADR and mark the previous one Superseded with a link. Preserve its historical reasoning.

Use the project's documented decision authority. Routine choices within an authorized task do not require a separate approval conversation.
